MAVEX Stats

Independent website statistics and analytics plugin for e107 CMS.

MAVEX Stats is a lightweight statistics plugin designed for the e107 content management system.

Features

Website visits and page-view tracking

Unique visitor measurement

Administrative statistics dashboard

Traffic and visitor analytics

Browser, operating system and device statistics

Bot and crawler filtering

Configurable data retention

Hungarian and English administration language support

Requirements

e107 CMS 2.x

PHP 8.1 or newer

Installation

Download the latest release.

Extract the mavex_stats directory into e107_plugins/.

Install the plugin through the e107 administration interface.

Configure the plugin settings.

For detailed Hungarian installation instructions, see mavex_stats/INSTALL_README_HU.txt.

Privacy

The plugin is designed to avoid storing visitors' IP addresses. See the documentation and plugin settings for details about collected data and retention.
